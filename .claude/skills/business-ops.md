# business-ops skill

## Descripción
Skill para operaciones de negocio digital orientado a LATAM.

## Cuándo activarse
- El usuario menciona Counter CRM, clientes, ventas
- Pide generar contenido para redes sociales
- Habla de automatizaciones de n8n
- Pregunta sobre estrategia de negocio

## Comportamiento
1. Siempre preguntar el contexto antes de actuar
2. Usar el modelo más económico para la tarea
3. Guardar en memoria todos los datos de clientes mencionados
4. Conectar con n8n cuando sea necesario ejecutar acciones

## Herramientas habilitadas
- bash (para operaciones del servidor)
- browser (para research de mercado)
- files (para documentos de propuestas)
- n8n webhook (para automatizaciones)
